## 0x01. 项目概览

### 设计哲学
将《EVA》MAGI 战术指挥中心美学与《路人女主的养成方法》泽村·英梨梨傲娇人格化交互融合，构建「活着的」虚拟终端，而非静态博客。

### 三大支柱
1. **Immersion 沉浸感** — MAGI 三贤人、AT 力场、LCL 流体、矩阵雨
2. **Performance 极致性能** — RenderCore 帧率锁定、Web Worker、MobilePerf 分级渲染
3. **Headless 无头架构** — 前端纯静态，WordPress + Cloudflare Workers + 自建服务器（RAG）

### 技术栈
| 层 | 技术 |
| :--- | :--- |
| 前端 | 原生 Vanilla JS（无框架）+ Tailwind CSS（打包版）+ 自定义 CSS |
| 字体 | JetBrains Mono / Space Grotesk / Noto Sans JP / Noto Serif SC（fonts.loli.net 镜像） |
| 图标 | Lucide 0.294.0 |
| 搜索 | Fuse.js 7.0.0（客户端模糊搜索） |
| 地图 | Leaflet 1.9.4（懒加载，About 视图圣地巡礼） |
| 边缘层 | Cloudflare Workers（API 网关 + JWT 签发 + KV 限流） |
| 数据源 | WordPress REST API（本地主源 + InfinityFree 灾备）+ Bangumi + Steam + Pixiv |
| AI | Google Gemini（Worker 注入 Key）+ 自建 RAG（Qdrant + FastAPI） |

### 6.2 视图切换状态机（ViewCommander）

```

  ↓

  ↓ setTimeout 220ms
```

### 6.3 认证状态机（Visitor ↔ Commander）

```
[Visitor] ──/auth 或 /login 或 徽章点击──> SecurityProtocol.open()
                                              ↓
                                          ID + Key 输入
                                              ↓
                                          submit() 三阶段动画
                                              ↓
                                          POST /auth (api-worker.wh1te.top)
                                              ↓
                              ┌─────────────┴─────────────┐
                          成功 JWT                      失败
                              ↓                            ↓
                    handleGranted(pilotId)         handleDenied('AT力场全开')
                    localStorage:                    (计数器+1，5次锁定10min)
                      magi_access='commander'
                      commander_id=<id>
                    清空 chatHistory
                    updateChatUI() 更新徽章
                              ↓
                          [Commander]
                              ↓
                       /logout 或徽章点击
                              ↓
                    移除 magi_access / commander_id
                    清空 chatHistory
                              ↓
                          [Visitor]
```

权限差异：
- **Visitor**：`GUEST_SYSTEM_PROMPT`，对话限 3 次/日（Worker 层 KV 限流），单句 <50 字
- **Commander**：`SYSTEM_PROMPT`，无限对话，允许长篇探讨

## 0x09. 关键 Bug 修复记录

### 9.1 ArticleViewer DOM 嵌套陷阱（2026-01-28）

- **症状**：文章阅读器渲染完成但 `clientHeight/Width = 0`，页面完全看不见内容
- **根因**：`#article-viewer` 运行时被错误嵌套进 `#about-view-container`，后者非 about 视图时 `display: none`，递归剪除子元素
- **修复**：`ArticleViewer.init()`（main.js L5020）检测父元素，非 body 则 `document.body.appendChild(this.overlay)` 强制迁移
- **教训**：`display: none` 的优先级高于任何内联样式，DOM 位置错误无法用 CSS 修复

### 9.2 搜索 data-id 重构（2026-02-06）

- **旧实现**：解析卡片 `onclick="ArticleViewer.open(${id})"` 字符串提取 ID（脆弱）
- **新实现**：BlogManager.renderPage（L3762）生成 `<article data-id="${id}">`，searchArticles（L3266）直接 `card.getAttribute('data-id')` 做 DOM 显隐
- **收益**：稳定性大幅提升，不再依赖字符串解析

### 9.3 Authorization 头净化

- **症状**：登录后请求 Gemini 返回 401 Unauthorized
- **根因**：Worker 把 `Authorization: Bearer <MAGI_TOKEN>` 原样透传给 Google，Google 误判为 OAuth 令牌
- **修复**：Worker 转发前剥离 `Authorization` 头，仅保留 URL `key=` 参数

### 9.4 反射式 API Key 泄露

- **漏洞**：访问 Worker 根路径 `/` 时透明转发至 Gemini，Google 404 页面回显完整 URL，导致 API Key 明文暴露
- **修复**：根路径强制拦截 + NERV 风格自定义 403，切断反射路径；同时切换为严格白名单转发（仅 `/v1beta/`）
